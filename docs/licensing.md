# Licensing & Usage Rights | 许可证与使用权

本项目会索引来自不同作者和组织的代码、模型、工具与服务。它们可能采用完全不同的许可和使用条款。

## 基本规则

- 本仓库的文档许可，不会自动授予上游代码、模型权重、数据集、图片、视频、声音或商标的使用权。
- 对每个上游资源，优先链接到其官方 LICENSE、模型卡、服务条款或使用政策。
- 不确定时标记 **License unclear / 待核验**，不要推断为开源或可商用。
- “可下载”“开放权重”“开源代码”不必然意味着可以无限制商用。
- 商业使用、再分发、生成内容权利、署名、衍生作品和地域限制应分别核验。

## 建议记录

| 项目 | 需要记录的内容 |
|---|---|
| Code license | 代码仓库的许可证及版本 |
| Model license | 权重许可证、模型卡和附加限制 |

| Dataset rights | 训练/评测数据集的来源与使用限制 |
| Media rights | 角色、肖像、声音、音乐和素材授权 |

## 用户责任

使用者应在部署或商业使用前自行阅读最新上游条款，并确认其使用场景、地域、素材来源和输出内容符合适用法律及平台政策。本文件不是法律意见。
