# Taxonomy | 内容分类规范

本文件定义 Hub 中不同资源的边界，避免把所有 AI 项目都混称为 Skill。

## 1. Agent Skill

**定义：** 一组供 AI Agent 按照明确指令完成特定任务的可复用技能文件。

**最低识别条件：** 项目中存在实际的 `SKILL.md`，并且文件内容描述了技能用途、触发场景和执行方式。仅有 README、模型权重、API 或节点代码，不足以认定为 Agent Skill。

记录字段：名称、技能范围、上游来源、Skill 文件位置、安装方式、依赖、许可证、版本/核验日期、限制。

## 2. Model

用于生成或理解图像、视频、音频、文本、动作或 3D 内容的模型/权重/API。

记录字段：模态、任务、官方来源、权重/API 获取方式、许可证与模型条款、硬件/服务要求、版本、限制。

## 3. Tool

可独立使用的软件、桌面应用、命令行程序或在线服务。

记录字段：平台、用途、官方文档、安装方式、许可证/定价、系统要求、版本。

## 4. Node / Plugin

依赖宿主软件运行的扩展，例如节点式工作流平台的自定义节点。

记录字段：宿主平台及版本、安装步骤、依赖、节点能力、许可证、兼容性。

## 5. Workflow

把多个工具、模型或人工步骤串联起来的制作流程。工作流不是 Skill，除非另有可验证的 Agent Skill 文件。

记录字段：目标、输入、步骤、工具链、参数、输出、质量检查、失败处理、测试环境。

## 6. Reference

术语表、技术说明、制作规范、评测报告和外部资料。引用时应注明来源、日期和适用范围。

## 状态标签

- **Verified**：关键事实已由官方来源核验。
- **Tested**：在注明的环境中实际执行过。
- **Needs review**：信息可能过期或尚未完成核验。
- **Archived**：上游已归档或不再维护。
- **License unclear**：许可或使用条款尚不明确。

Verified 不等于 Tested；官方仓库存在也不等于项目仍在积极维护。
