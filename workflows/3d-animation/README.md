# 3D Animation Workflow | 3D 动画制作流程

**状态：** 通用制作蓝图，未实测。

## 生产阶段

1. **预制作**：剧本、角色设定、资产清单、分镜和镜头表。
2. **资产制作**：建模、拓扑、UV、材质、贴图与资产命名。
3. **角色绑定**：骨骼层级、控制器、权重绘制、变形测试。
4. **动画**：阻挡关键帧、动作曲线、接触点、重心和过渡。
5. **布局与镜头**：场景尺度、相机、构图、焦距和镜头运动。
6. **灯光与渲染**：色彩管理、渲染引擎、采样、降噪和分层输出。
7. **合成与后期**：合成通道、调色、景深、运动模糊和声音。
8. **交付归档**：工程文件、贴图、缓存、插件版本和最终成片。

## 每镜头 QC

- 动作曲线无突跳，循环首尾衔接
- 角色无明显穿插、滑步和权重塌陷
- 相机运动平滑，构图和景深符合分镜
- 灯光、材质和色彩跨镜头一致
- 渲染输出无丢帧、黑帧或错误通道
- 项目依赖和第三方资产许可已记录

## 建议工具

以 [Blender](https://www.blender.org/) 为主要 DCC 入口。根据项目需求再选择实时引擎、合成软件和渲染农场；具体插件不应在未核验兼容性前写成强制依赖。
