# Wan2.2 Animate + ComfyUI | 角色动画与角色替换

**状态：** 官方流程整理 / 本仓库未实测。  
**官方依据：** [Wan2.2 官方仓库](https://github.com/Wan-Video/Wan2.2) · [ComfyUI 官方教程](https://docs.comfy.org/tutorials/video/wan/wan2-2-animate)

## 能做什么

Wan2.2-Animate 提供两类主要用途：

- **Move / Animation**：用驱动视频中的人物动作与表情，驱动参考角色图像。
- **Mix / Replacement**：把原视频中的人物替换为参考角色，同时尝试保留动作、表情和环境融合。

## 输入素材

- 一张清晰、获得授权的角色参考图
- 一段获得授权的驱动视频
- 明确目标：Move 或 Mix
- ComfyUI 与教程要求的模型、节点和依赖

## 安装前检查

1. 阅读官方教程与模型页面，确认当前工作流版本。
2. 确认显存、磁盘空间、Python/PyTorch/CUDA 版本满足要求。
3. 根据官方工作流安装缺失节点。教程当前列出的节点包括 ComfyUI-KJNodes 与 ComfyUI ControlNet Auxiliary Preprocessors；版本更新时以教程为准。
4. 下载模型权重前，核验各权重的许可和文件来源。
5. 首次运行使用短视频、小尺寸测试，避免直接跑长片段。

## 制作步骤

1. 在 ComfyUI 中载入官方 Wan2.2 Animate 工作流。
2. 为参考图节点加载角色图像。
3. 为视频节点加载驱动视频。
4. 选择 Move 或 Mix 模式。
5. 检查姿态/面部预处理结果，确认主体追踪完整。
6. 使用低成本设置运行测试片段。
7. 检查角色身份、动作、表情、遮挡和背景融合。
8. 通过测试后再提高分辨率或延长片段。
9. 导出视频，进入剪辑、调色和声音同步阶段。

## 质量检查

- 人物是否完整出现在画面中
- 参考角色的脸、服装、比例是否稳定
- 手脚和身体是否出现变形或多余肢体
- 遮挡关系和人物与环境的接触是否自然
- 连续帧是否闪烁或身份漂移
- 长片段分段拼接是否有跳变
- 输出帧率、分辨率和时长是否符合交付要求

## 故障排查方向

| 现象 | 检查方向 |
|---|---|
| 显存不足 | 降低分辨率/片段长度，检查官方低显存选项和模型卸载策略 |
| 姿态不准 | 检查驱动视频清晰度、遮挡和预处理结果 |
| 角色外观漂移 | 检查参考图质量、连续性描述和分段条件 |
| 背景融合差 | 检查原视频光照、运动模糊和遮挡边界 |
| 节点缺失 | 按 ComfyUI Manager 提示及官方教程安装匹配版本 |

## 许可与肖像

代码、权重、第三方节点和输入素材分别遵守各自条款。必须获得人物肖像、表演视频和声音的适当授权；不得用于未经同意的冒充或欺骗性合成。
