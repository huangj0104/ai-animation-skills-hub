# Motion Graphics Workflow | MG 动画工作流

**状态：** 通用制作蓝图，未实测。

## 适用场景

品牌片头、产品介绍、数据可视化、字幕包装、信息图动画、社交媒体动态海报和解释视频。

## 工作步骤

1. **内容结构**：确定核心信息、受众、平台、画幅、时长和 CTA。
2. **视觉系统**：定义字体、色板、网格、图标、插画风格和动效曲线。
3. **分镜/节奏板**：按时间码安排信息层级、转场和画面停留时间。
4. **资产准备**：整理矢量图、字体、图标、品牌素材和数据来源。
5. **动效制作**：用关键帧或程序化组件控制位置、缩放、透明度、路径和遮罩。
6. **声音设计**：为关键动作配置提示音、转场音、旁白和背景音乐。
7. **多画幅适配**：检查 16:9、9:16、1:1 的安全区、字号和信息密度。
8. **导出与质检**：检查帧率、编码、字幕、品牌规范和版权。

## 可评估工具

- [Remotion](https://www.remotion.dev/)：React/TypeScript 程序化视频。
- [Motion Canvas](https://motioncanvas.io/)：TypeScript 动画场景。
- [Manim Community](https://www.manim.community/)：数学与技术解释动画。
- [Blender](https://www.blender.org/)：3D 标题、空间图形和合成。

## 交付清单

- 分镜/节奏板
- 字体、图标和素材来源清单
- 动效参数与项目文件
- 配音、音乐和音效分轨
- 发布画幅导出文件
- 授权与质量检查记录
