# AI Short Film Workflow | AI 短片制作流程

**状态：** Draft workflow / 待实测。此文档是制作蓝图，不代表所有模型或节点已安装。

## 目标

把一个短片创意拆成可管理的制作任务，完成分镜、资产生成、镜头制作、声音、剪辑和交付。

## 阶段 1：前期制作

1. 使用 [animation-production-planner](../../skills/preproduction/animation-production-planner/SKILL.md) 形成制作简报。
2. 输出角色圣经、场景/道具清单、分镜和镜头表。
3. 为每镜确定生成方式：实拍/素材、图像生成、图生视频、文生视频、Blender、程序化动画或混合方案。
4. 标记需要人工确认的镜头和版权风险。

## 阶段 2：资产准备

- 先制作角色参考图、表情/服装视图和场景参考。
- 给角色和场景分配稳定 ID。
- 建立资产登记表：来源、作者、下载日期、许可证/授权和用途。
- 对参考图的角色、服装、道具和构图建立文字描述，减少跨镜头漂移。

## 阶段 3：镜头生产

- 先做低成本预览或关键帧，再制作完整镜头。
- 记录模型版本、工作流、提示词、参数、随机种子和输入资产。
- 对高风险镜头准备替代方案，例如分层合成、实拍素材、Blender 或静帧动效。
- 不要仅凭单次生成判断模型稳定性。

## 阶段 4：声音与剪辑

- 先锁定对白/旁白文本和时间轴。
- 生成/录制声音后再调整镜头节奏。
- 对口型镜头单独检查音画同步。
- 使用剪辑工具完成镜头排序、节奏、字幕、音乐和混音。

## 阶段 5：质量检查与交付

- 角色、服装、场景、道具连续性
- 动作连贯性、物理合理性和时间一致性
- 文字、手部、人脸和背景伪影
- 音画同步、响度、字幕和编码
- 画幅、安全区、帧率和分辨率
- 素材来源、肖像/声音授权和许可证

## 交付记录

保留最终视频、项目文件、分镜、镜头表、提示词、资产登记、模型/软件版本和 QC 报告。未经授权的原始素材不得打包公开。
