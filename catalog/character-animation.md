# Character Animation | 角色动画资源目录

> 本页聚焦角色动作驱动、角色替换、表情迁移与数字人动画。模型能力不等于 Agent Skill；请分别核验代码、权重和输入素材的使用权。

## 首批重点项目

| 项目 | 类型 | 能力 | 官方来源 | 说明 |
|---|---|---|---|---|
| Wan2.2-Animate-14B | 角色动画模型 | 使用表演视频驱动参考角色，或将视频中的角色替换为参考角色；支持动作与表情复制 | [Wan2.2 官方仓库](https://github.com/Wan-Video/Wan2.2) | 官方 README 提供预处理和推理流程；14B 模型资源需求较高，需按官方指南核对硬件 |
| LivePortrait | 肖像动画项目 | 用驱动视频/动作控制静态肖像的头部与表情运动 | [官方仓库](https://github.com/KlingAIResearch/LivePortrait) | 注意上游 README 对 InsightFace 检测模型的非商业研究限制；商用前需单独核验 |
| MuseTalk | 音频驱动口型项目 | 让人脸视频与输入语音口型同步 | [官方仓库](https://github.com/TMElyralab/MuseTalk) | 主要解决口型区域，不等同于完整身体动作生成 |

## 任务选择

- **整身动作迁移/角色替换**：先评估 Wan2.2-Animate。
- **静态肖像头部与表情驱动**：评估 LivePortrait。
- **语音口型同步**：评估 MuseTalk，并单独检查音频质量和音画偏移。
- **传统 3D 角色动画**：使用 Blender 等 DCC 工具处理骨骼、绑定、动作曲线和镜头。

## 通用制作流程

1. 确认参考角色图与驱动视频均已获授权。
2. 检查人物是否完整可见、遮挡、镜头运动、帧率和光照。
3. 预处理驱动视频，检查姿态/面部跟踪质量。
4. 先用短片段和低分辨率验证，再制作完整镜头。
5. 检查面部、手部、服装、身体比例、遮挡关系和背景稳定性。
6. 与对白/旁白时间轴对齐，必要时再做口型修正和合成。
7. 保存模型版本、参数、输入来源、授权记录和 QC 结果。

## 重要限制

- 不得把未经同意的真实人物肖像或声音用于冒充、欺骗或未经授权的克隆。
- 模型生成结果可能存在肢体畸变、身份漂移、遮挡错误和背景闪烁。
- 代码许可证不自动授予训练数据、模型权重、人物肖像或声音的权利。
