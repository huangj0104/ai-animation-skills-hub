# Character Motion Production

## Purpose | 目标

把角色动画需求转化为可执行的镜头制作方案。本 Skill 负责选择与规划工作流，不声称模型已安装或生成成功。

## Safety & rights | 授权要求

- 仅使用获得授权的角色图像、驱动视频、肖像和声音。
- 不协助制作未经同意的真实人物冒充、欺骗性深度伪造或声音克隆。
- 记录素材来源、授权人、用途范围和有效期。
- 单独核验代码、模型权重、检测模型和第三方节点的许可。

## Inputs | 输入

- 目标角色参考图/角色模型
- 驱动视频、动作序列或语音（如适用）
- 任务类型：动作迁移、角色替换、肖像动画或口型同步
- 目标时长、帧率、分辨率和画幅
- 可用硬件、软件与模型
- 素材授权与发布用途

## Workflow | 执行步骤

1. **任务分类**：明确要复制全身动作、替换视频人物、驱动头部表情，还是只同步口型。
2. **素材检查**：确认主体可见、动作完整、镜头稳定性、遮挡、光照、帧率和授权。
3. **方法选择**：全身动作/替换可评估 Wan2.2-Animate；肖像表情可评估 LivePortrait；音频口型可评估 MuseTalk；传统 3D 可选 Blender 骨骼动画。
4. **连续性定义**：固定角色身份特征、服装、发型、体型、道具、场景和镜头方向。
5. **预处理**：按所选项目官方指南执行姿态/人脸/视频预处理；保存中间结果并检查跟踪失败。
6. **小样测试**：先选择短片段、低分辨率和少量帧，验证动作、身份、遮挡与背景。
7. **正式生成**：锁定版本和参数；按镜头分批执行，记录失败镜头。
8. **后期修复**：必要时使用合成、遮罩、局部重绘、稳定、补帧或人工修正。
9. **质检**：检查脸部、手部、肢体比例、接触点、脚滑、穿插、闪烁、身份漂移和音画同步。
10. **归档**：保存输入授权记录、参考资产、模型版本、参数、输出和 QC 结果。

## Decision guide | 方法选择

| 需求 | 优先评估 |
|---|---|
| 从真人驱动视频迁移动作到角色图 | Wan2.2-Animate |
| 用角色替换原视频人物 | Wan2.2-Animate |
| 静态肖像产生头部/表情运动 | LivePortrait |
| 语音驱动嘴部同步 | MuseTalk |
| 可控骨骼、镜头和物理动作 | Blender |

## Outputs | 输出

- 角色连续性说明
- 输入素材检查表
- 模型/工具选择及理由
- 镜头级执行计划
- 生成记录与失败项
- 质检报告和授权记录

## Acceptance criteria | 验收标准

- 动作与参考驱动一致且无明显跳变
- 角色外观、服装、道具跨镜头稳定
- 无明显肢体畸变、穿插和背景闪烁
- 口型与音频时间轴对齐（如适用）
- 所有输入素材和输出用途均有明确授权依据
- 未实测的能力明确标记为待验证
