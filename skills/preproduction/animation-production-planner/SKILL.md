# Animation Production Planner

## 目标

把模糊创意整理成可交付给人工或后续生成工具的前期制作文件。此 Skill 负责规划，不假装已经生成视频或完成渲染。

## 工作原则

- 先明确目标受众、平台、画幅、时长、风格和交付格式。
- 将事实、创意假设和待确认事项分开。
- 建立角色、服装、道具、场景和色彩的连续性约束。
- 每个镜头都要有可视化动作，不写只有抽象情绪的空泛提示词。
- 生成提示词按镜头独立组织，并保留全片一致性描述。
- 对未知素材来源、肖像/声音权利和模型许可明确标记，不擅自认定可商用。

## 输入

尽可能从用户请求中提取：

- 项目目标、受众、平台与发布用途
- 故事梗概、主题、旁白/对白
- 目标时长、画幅（16:9、9:16、1:1 等）
- 视觉风格、参考作品或参考图
- 角色、场景、道具及其已知特征
- 可用模型、软件、硬件和预算
- 内容限制、授权情况和截止时间

如果关键约束缺失且会改变制作方案，只问最重要的一项；其他信息可先以明确标记的假设推进。

## 执行流程

1. **制作简报**：用一句话定义目标，写出受众、平台、时长、画幅、风格和成功标准。
2. **故事结构**：拆分开场、铺垫、发展、转折和结尾；广告/短视频可采用问题—展示—证明—行动号召结构。
3. **角色圣经**：为每个角色记录年龄段（仅在创作需要时）、外观、服装、配色、体态、性格、声音特征和不可变化项。不要推断真实人物敏感属性。
4. **场景与道具**：记录地点、时间、光线、空间关系、关键道具和连续性约束。
5. **分镜**：逐镜写出时长、景别、机位、镜头运动、画面动作、对白/旁白、声音、转场和生成方式。
6. **镜头清单**：为每个镜头分配唯一 ID，标记素材需求、参考帧、生成模型候选和后期任务。
7. **提示词包**：每镜输出正向描述、必要的负面约束、角色一致性描述、运动描述和镜头语言。不要依赖“保持一致”这种无具体特征的表述。
8. **风险与制作计划**：标注高难镜头、文字生成风险、手部/人脸风险、复杂交互、授权和算力风险，并给出替代方案。
9. **验收**：检查总时长、角色一致性、镜头覆盖、叙事连贯、声音规划、素材权利和交付规格。

## 默认交付结构

```text
project/
├── brief.md
├── story-outline.md
├── character-bible.md
├── world-and-assets.md
├── storyboard.md
├── shot-list.csv
├── prompts/
│   └── shot-001.md
└── production-plan.md
```

## 镜头提示词格式

每镜应包含：

- Subject：主体及可识别特征
- Action：可观察、可执行的动作
- Environment：场景、时间、天气、背景
- Camera：景别、角度、运动、焦点
- Lighting & style：光线、色彩、材质与风格
- Timing：动作起止、节奏、镜头时长
- Continuity locks：角色、服装、道具、空间关系
- Avoid：不希望出现的伪影或错误（仅在目标模型支持时使用）

## 质量门槛

- 每个镜头都有明确的叙事目的。
- 角色外观与服装在镜头间可追踪。
- 画面动作可见且与旁白/对白时间匹配。
- 镜头时长之和与目标时长一致，或明确解释留白/片头片尾。
- 关键素材和声音都有来源/授权状态。
- 未测试的模型和工具标为候选，不声称可用。
